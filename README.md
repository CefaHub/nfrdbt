# Gift Radar

Телеграм-бот, который присылает свежие коллекционные подарки с записью о первоначальном получателе — «кому подарили».

## Уведомление

Пример:

**Spiced Wine #108832**

https://t.me/nft/SpicedWine-108832

Кому подарили: @username  
Модель: ...  
Фон: ...  
Символ: ...

Под сообщением две кнопки: **Открыть подарок** и **Профиль получателя** (если Telegram раскрыл публичный username). Ссылка на NFT показывает превью средствами Telegram.

Первый получатель — не обязательно нынешний владелец. Бот не пытается угадывать личность по отображаемому имени. Если сохранился только Telegram ID, он показывается в тексте, без ненадёжной кнопки.

## Команды

- `/start` — подключение и справка.
- `/status` — состояние сканирования и доставки.
- `/last` — последние подходящие NFT.
- `/pause` и `/resume` — выключить и включить уведомления.

Для технической проверки доставки остаётся скрытая команда `/testdelivery`. Уже использованный код привязки не меняется.

## Как работает

Источники — Telegram MTProto и бесплатный WebSocket see.tg. Из see.tg бот подписывается **только на события new**. Каждое событие перепроверяется через Telegram API. Уведомление отправляется, только если в `StarGiftAttributeOriginalDetails` указан исходный получатель. Листинги, продажи, изменения цен и обычные подарки без получателя не присылаются.

Два источника не создают двойных уведомлений: NFT дедуплицируются по ссылке/номеру. Очередь переживает перезапуск. Если see.tg отключает `new`, остаётся сканирование Telegram; оно может отставать из-за ограничений API.

## Bothost

1. Обнови код из ветки `main`.
2. Проверь переменные окружения по `.env.example`: нужны `BOT_TOKEN`, `SESSION_STRING` и Telegram API ID/hash.
3. Перезапусти бота, затем отправь `/status`.

WebSocket доступен без ключа. `SEE_TG_API_TOKEN` необязателен, хранить его следует только в переменных окружения Bothost. Платные REST-методы see.tg не используются.

`/app/data/state.json` хранит привязку аккаунта, активацию, историю и счётчики NFT. Во время обновления **не удаляй папку data**. Старые записи сохранены для совместимости, но прежние механизмы сделок больше не запускаются.
