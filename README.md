# NFT Gift Radar — коммерческая версия для Bothost

Приватный Telegram NFT-радар с автовыдачей **одноразовых ссылок активации**.
Источники — Telegram MTProto и бесплатный поток see.tg. Как и ранее,
радар отбирает подарки с информацией об исходном получателе, но теперь в
сообщении **показывается реальный владелец NFT**, а не человек, которому
подарок был вручён в первый раз. Владелец берётся из Telegram
`starGiftUnique.owner_id` (либо `owner_name` / `owner_address`, когда
Telegram не раскрывает владельца как профиль). Кнопка **«Профиль владельца»**
ведёт только на подтверждённый публичный Telegram username владельца.
Если известен только ID, имя без публичного username или TON-адрес, бот
покажет эти сведения без фальшивой кнопки. Для редких случаев, когда
владелец не указан Telegram, отобразится «Владелец: Не указан».

## Безопасность и доступ

**Единственный администратор — Telegram ID `8714018880`.**

Только этому аккаунту доступны генерация ссылок, /admin, /stats, /status
сканера, /pushall, /flush, /check, /last и /pause /resume. Никакие старые
ключи /activate, приглашения старой версии или прежний owner_id
не дают прав администратора.

Другие пользователи могут только активировать персональную покупку,
получать NFT-уведомления, проверять свою подписку и отключать доставку.
Пользователи **не видят друг друга**, публичного списка подписчиков нет.
Даже администратору бот показывает только общую статистику **без чужих ID**.

**Ограничение анонимности:** для доставки Telegram Bot API/MTProto нужен
chat_id получателя, поэтому он хранится в закрытой SQLite на хостинге.
Telegram и администратор хостинга технически могут иметь доступ к этим
данным. Это приватность между покупателями, а не абсолютная анонимность.

## Продажа через автовыдачу

1. Обнови Bothost до текущего `main` и перезапусти процесс. **Не удаляй
   `/app/data` при обновлении**: там находятся сессия, радар и лицензии.
2. С аккаунта **8714018880** напиши боту `/admin`, затем `/links 20`.
3. Бот выдаст 20 разных ссылок вида:
   `https://t.me/your_bot?start=RANDOM_CODE`.
4. Положи эти ссылки в инвентарь **автовыдачи по одной на покупку**.
5. Покупатель открывает свою ссылку, жмёт Start; доступ активируется
   автоматически, и новые NFT начинают приходить ему в личный чат.
6. Для ещё одной партии — снова `/links 20`, `/links 50` и т.д.
   **Нет общего лимита на число ссылок или подписчиков.** За одну команду
   бот создаёт до 50 ссылок для удобства Telegram-сообщений.
7. Ссылка **одноразовая**, бессрочная; после активации другим человеком не
   сработает. База хранит только SHA-256 хеш кода, не сам секрет.
   Не выкладывай одну и ту же ссылку для нескольких продаж.

Новый покупатель получает только NFT, обнаруженные после подключения.
Старые сообщения и накопленные до продажи находки не рассылаются.

## Команды

### Только администратор 8714018880
- `/admin` или `/start` — панель.
- `/invite` — одна ссылка автовыдачи.
- `/links N` — партия от 1 до 50 ссылок, повторять без ограничений.
- `/stats` — агрегированная статистика продаж и подписок, без ID.
- `/status` — здоровье источников и доставки.
- `/pushall` — перепроверить недавние NFT и пробудить доставку.
- `/flush` — только пробудить доставку.
- `/last` — последние NFT.
- `/check SnakeBox-189137` — проверить конкретный подарок.
- `/pause` и `/resume` — остановить/возобновить рассылку.

### Покупатель
- `/start КОД` — автоматическая активация по ссылке, только один раз.
- `/status` — подтвердить свою подписку.
- `/stop` — выключить уведомления, не удаляя ранее купленный доступ.
- `/start` — снова включить ранее отключённые уведомления.

Посторонний аккаунт не сможет создать ссылку даже со старым активационным
ключом. Несуществующие административные команды не выводят админ-меню.

## Хранение и масштабирование

`/app/data/commercial.sqlite3` — лицензии, SHA-256 кодов, одна общая
запись для каждого NFT и индивидуальный курсор доставки для каждого клиента.
Один найденный NFT хранится **один раз**, не дублируется N раз в JSON.
`/app/data/state.json` — курсоры сканера и последние найденные NFT.

При первом запуске новая версия переносит прежних подписчиков из state.json
в SQLite. Прежний владелец становится обычным получателем, если его ID
отличается от `8714018880`; управлять может только новый администратор.
Не удаляй state.json или commercial.sqlite3 между перезапусками.

*«Безлимитно» означает отсутствие программного лимита пользователей и
общего числа ссылок.* Фактическая скорость доставки ограничена Telegram
(частота отправки, FloodWait), ресурсами тарифа Bothost, диском и нагрузкой.
Например, десятки тысяч подписчиков нельзя гарантированно уведомить за
секунду с одной Telegram-сессии.

## Переменные Bothost

Основные:
- `BOT_TOKEN` (после передачи токена в переписке безопаснее перевыпустить).
- `SESSION_STRING` запасного аккаунта (держи только в секрете Bothost).
- `TELEGRAM_API_ID` / `TELEGRAM_API_HASH` — собственные ключи предпочтительнее.
- `DATA_DIR=/app/data`.

Остальные см. `.env.example`. Главный файл `main.py`. Бот не делает
покупок, не рассылает сообщения владельцам NFT и не обещает обнаружить
каждый выпуск мгновенно.
